# Calculator (Python)

## О проекте:
Это мой первый личный GUI проект.
В рамках него мне хотелось закрепить знания по теме ООП а также встроенной в Python графической библиотеки Tkinter.
Весь код написан вручную, для его коррекции использовался линтер Ruff со стандартными настройками. 
Проект не идеален и имеет определенное количество багов, однако он полностью справляется со своей задачей.
Я собрал версии под разные ОС в обычные исполняемые файлы, их можно скачать в Releases и протестировать.
Из за особенностей каждой ОС внешний вид приложения может несколько отличаться. 
Разработка приложения велась на Ubuntu 24.04 (ARM) поэтому эталонно приложение выглядит именно на ней.

## Функционал и скриншоты
Калькулятор может выполнять базовые математические операции с целыми и дробными числами: сложение, вычитание, умножение и деление. 
Приоритет операций можно задавать скобками.
